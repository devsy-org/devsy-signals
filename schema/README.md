# Envelope schema

`envelope.schema.json` references `audit-data.schema.json`, generated from `audit-allowlist.json` by `go run ./cmd/genauditschema` in `tools/`, and `record-depth.schema.json`, generated by `go run ./cmd/gendepthschema` in `tools/`. Load all three when validating. The depth schema counts objects and arrays, including the envelope object, just as the Go decoder does.

`tools/schematest/go_only.json` lists schema-valid fixtures that Go must reject, with a one-line reason for each exception. The differential test requires both verdicts for each listed fixture and requires agreement for every unlisted fixture.
